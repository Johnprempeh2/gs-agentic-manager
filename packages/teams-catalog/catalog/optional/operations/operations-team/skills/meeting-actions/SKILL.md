# Meeting Actions

Use this skill when notes or a transcript from a meeting are attached to your task.

## Format

**[Meeting name], [date]**

Attendees: names as given in the notes.

1. **Decisions**: one line each, in the words the meeting used.
2. **Actions**: a table.

| Action | Owner | Due | Status |
| --- | --- | --- | --- |
| | | | |

3. **Open questions**: what is not settled, and who will answer it.
4. **Next meeting**: date, if set.

## Rules

- Only what the notes say. If something is unclear, list it under open questions.
- One owner for each action. "Team" is not an owner.
- Leave out personal or sensitive details that the actions do not need.
- The action list goes to the human overseer for approval before anyone receives it.
- Write in British English and plain words.
