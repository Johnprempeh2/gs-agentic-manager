# KPI progress paths

Open a KPI in Goals and edit its plan to choose a progress path.

- **Straight line** compares each reading with the progress due on its reading date. A shortfall can turn amber or red before the deadline. The gap uses both the whole target change and progress due so a zero reading does not look green against a large target.
- **Target by date** stays green before the target date when a reading exists. On the target date, it turns red if the target is not met. Use this for outcomes that arrive in whole steps, such as signed clients or completed installations.

Existing KPIs use Straight line until an owner changes them. A KPI still needs a target, target date and reading before it has a status. Draft KPIs have no status.
